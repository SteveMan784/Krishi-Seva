Firebase activation steps
  1. Add your public Firebase web configuration in js/firebase-config.js. Do not add private keys.
  2. Enable Email/Password and Phone authentication, authorize the hosting domain, configure SMS regions, and create a Firestore database.
  3. Install dependencies with npm ci && npm --prefix functions ci, then deploy with npm run deploy -- --project YOUR_PROJECT_ID (Cloud Functions requires billing).
  4. From a trusted terminal with Application Default Credentials, set FIREBASE_PROJECT_ID, ADMIN_EMPLOYEE_ID, ADMIN_NAME and ADMIN_PASSWORD, then run npm run bootstrap:admin.
  5. Sign in as admin, add your mandis, create staff accounts, and publish dated shift capacities. No demo accounts or capacities are created automatically.

22 Indian Languages (8th Schedule) & Registration

Probable AI Waiting Time Engine

03

4 Operational Shift Booking

Farmers book realistic mandi shifts: Early Morning Intake (7-10 AM), Standard Weighbridge (10 AM-1 PM), Afternoon Quality (1:30-4:30 PM), or Evening Payout (4:30-7 PM).

Instant bank disbursement via Aadhaar Payment Bridge / NPCI with official Bank UTR number. Generates official Government APMC procurement receipts.
